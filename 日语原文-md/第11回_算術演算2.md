## 2進数の除算

符号付き除算  
被除数＝商×除数＋剰余  
例)  
(+7)/(+2) = (+3)余り(+1)  
(-7)/(-2) = (+3)余り(-1)  
(-7)/(+2) = (-3)余り(-1)  
(+7)/(-2) = (-3)余り(+1)  
(+7)/(-2) = (-4)余り(-1)  
被除数の符号と剰余の符号は  
同じでなければならない

## 乗算・除算命令

```
mult $s2, $s3
```

`Hi, Lo = $s2` **×** `$s3`

```
multu $s2, $s3
```

`Hi, Lo = $s2` **×** `$s3`

```
div $s2, $s3
Lo = $s2 / $s3,  Hi = $s2 % $s3
divu $s2, $s3
Lo = $s2 / $s3,  Hi = $s2 % $s3
mvhi $s1     # move from hi
$s1 = Hi
mvlo $s1     # move from lo
$s1 = Lo
```
