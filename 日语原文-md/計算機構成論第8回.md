## アセンブラ

– 機械語のプログラムコード

– 未定義のラベルを保持(外部参照に使用)

以下のC言語のソースコードをアセンブリコードに直せ。

```
void sort(int v[], int n){
int i, j;
for(i=0; i<n; i++){
for(j=i-1; j>=0 && v[j]>v[j+1]; j--){
swap(v,j);
}}}
exit1:
```

①レジスタの退避  
②引数の退避  
③外側のループ  
④内側のループ  
⑤swap呼出  
⑥内側のループ  
⑦外側のループ  
**⑧レジスタ復元～**

```
lw $s0, 0($sp)
lw $s1, 4($sp)
```

レジスタ復元

```
lw $s2, 8($sp)
lw $s3, 12($sp)
lw $ra, 16($sp)
addi $sp, $sp, 20
```

呼び出し元へ戻る

```
jr $ra
```
