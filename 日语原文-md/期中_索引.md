# 期中试卷转录索引 · 可读性总表与不可识别清单

## 1. 这份 PDF 里哪些内容可以转成文字

该 PDF 由 CamScanner 生成，**19 页全部是位图图像，没有文字层**（`get_text()` 每页返回 0 字符）。
因此不存在“复制文字”这条路径：全书内容都必须**读图**才能取字。实测结论是——
**绝大部分印刷内容都可读**；受限的不是整页，而是具体的**边缘裁切、反光和手写遮盖**。

提取方式：用 300 DPI 整页渲染（`pymupdf.get_pixmap(dpi=300)`）再读图。
注意：直接抽取内嵌 JPEG 反而更差——有些页的内嵌图比它所在的页面小（如 p14 内嵌仅 1593px 放到 842pt 页面上），
**内嵌图会丢掉页面渲染仍保留的一行印刷内容**。

**处理原则**：不做合并、不猜测年份。各版本**一律保留自己的印刷题号原文**，分别成文，重叠关系如实列出供对照。

## 5. 存疑但已按原样保留（未强行判定）

- **A 组 p03 (27) 与 C 组 p19 (27) 不一致**：纸质扫描作 `01100100`，屏幕照片作 `01100110`。两版都**原样保留**，未择一。
- **A 组 p03 (33)(B) 与 C 组 p19 (33)(B) 不一致**：p03 印成 9 位 `010001111`（8 位应为 `01000111`，多出一笔疑为下划线或扫描杂点），p19 为 8 位。两版都保留。
- **B 组 p06 (9)**：选项 (A) 与 (B) 印刷为**同一串** `11110100`。读图三遍确认如此，属**原卷印刷如此**，未作修正。
- **C 组 p16 (19)**：选项 (B)(C) 的浊点在该分辨率下不可分辨（キビ／ギビ），已按所见保留两个「キビ」。
- **`空欄`**：该词在 A／C 两组里印刷极小，属可读性边缘，按本卷惯用措辞读作「空欄」。
- **A 组 p19 (31)(A)**：手写笔迹压在该数值上（读作 `38`，覆盖笔画形似 `A`），属可读性边缘；已按所见保留 `38`。

> 上述前后不一致处，恰恰说明屏幕照片的分辨率会把 `0/6/8/9` 一类数字读歪；
> 凡有纸质扫描与屏幕照片两版的地方，**以纸质扫描为准**更稳妥，但两版都保留以便核对。

### 5.1 复核未能定论的两处（读数可靠性的实测证据）

p03 与 p19 拍的是**同一份印刷卷的同一节**（六、(26)–(35)），因此本该逐位相同。但：

- 两次独立转录在 **(27)** 与 **(33)(B)** 上给出了**不同读数**（见上两项）；
- 而一次**专门的逐位复核**却报告 p03／p19 在 (26)–(35) **「digit for digit」完全相同、无任何内容差异**。

三者不能同时成立。**我无法判定哪一方正确**，也**没有**据此改动原文，两版均按各自转录原样保留。
但这条矛盾本身是有用的结论：**该节的个别二进制位处于可读性边缘**，(27) 与 (33)(B) 应视为**不可完全确证**，
而非"两版原文不同"。做题时这两处建议依题目逻辑自行推算，不要依赖任一版转录的数字。

### 5.2 复核提出的读数风险（已如实记录，未擅改）

- **p19／p03 (31)(A)**：复核认为该处印刷值被手写笔画覆盖，读作 `38` 但**存在** `3A8` 的可能，属**低置信**；两处转录均作 `38`，成品保留 `38`。
- **p12 上缘的 (30)(31)(32) 选项行**：其题干在画面外，属**上一节**的尾部，**不是**纸质版六、(30)–(32) 的对应题。成品未把它们当作六、的题目拼接，仅在 `期中2021.md` 中按来源如实呈现。
- **p12 (34) 中 `1234ABCD` 的下标 `16`**：印刷极小，按 16 进制记号理解。

## 6. 题号对照：三组影像的编号互不对齐

**这是本 PDF 最容易踩坑的地方**：三组影像各自沿用不同的编号，同一个题号在不同组里往往是**完全不同的题**。

| (6)–(10) | 同上续 | 同上 | **与 A 组 (6)–(10) 逐字相同** |
| (11)–(15) | 二、正误判断 | 一、选择题（性能指标类） | 二、正误判断（与 A 组相同） |
| (16)–(20) | 三、穴埋め | 一、选择题（续） | 三、穴埋め（与 A 组相同） |
| (21)–(23) | 四、C→汇编 | 一、选择题（续） | 四、C→汇编（与 A 组相同） |
| (24)–(25) | 五、分支指令 | 三、正误判断 | 五、分支指令（与 A 组相同） |

关键结论：**A 组与 C 组高度重合**（六、完全同节，(11)–(25) 逐字相同），差别集中在**一、选择题**；

因此成品**按影像分组分别成文**，不做跨组重编号。
