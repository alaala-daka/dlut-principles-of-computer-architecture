构成处理器与存储器的元件:LSI

名称 中文含义 集成的晶体管数量
LSI (large scale integration) 大规模集成电路 集成一千～几十万个晶体管；特别指规模很大的 IC
VLSI (very -) 超大规模集成电路 集成几十万～几百万个晶体管
ULSI (ultra -) 特大规模集成电路 集成一千万个以上晶体管
术语 LSI 中的 scale 指的是集成度， 即一块芯片上能做出多少个晶体管/门电路；集成度越高，同一块芯片能实现的功能越复杂。

二进制与十进制的相互转换

二进制 → 十进制
1111₂ = 1×2³ + 1×2² + 1×2¹ + 1×2⁰
      = 1×8 + 1×4 + 1×2 + 1×1
      = 15₁₀
十进制 → 二进制（反复除以 2，取余数）
11 / 2 = 5  余 1
 5 / 2 = 2  余 1
 2 / 2 = 1  余 0
 1 / 2 = 0  余 1

11₁₀ → 1011₂   # 余数自下而上排列
权重对照（十进制 1111 的展开）
1111₁₀ = 1×1000 + 1×100 + 1×10 + 1×1
       = 1×10³  + 1×10² + 1×10¹ + 1×10⁰

位权： 10³   10²   10¹   10⁰
      1000   100    10     1
对比 二进制的位权是 2³ 2² 2¹ 2⁰ = 8 4 2 1， 十进制的位权是 10³ 10² 10¹ 10⁰ = 1000 100 10 1。

2 的补数的优点

  • 看最高位就能知道符号：
    • 1 → 负，0 → 正。
  • 没有 -0。
  • 加法可以简单地实现（减法可以转换为加法）。
  • 符号扩展也很容易。
    • 符号扩展：把值转换为使用更多位的值（8 bit → 16 bit）。
对比 绝对值表示法与 1 的补数都存在 -0，因此需要为「零」做特殊判断； 2 的补数把 0 与 -0 统一为 0000， 使得加法器电路可以不加修改地同时处理正负数。

2 的补数转换的正当性

问题 为什么「逐位取反再加 1」就能得到负数？
证明
①  a₃a₂a₁a₀ + ~a₃~a₂~a₁~a₀ = 1111₂
②  a₃a₂a₁a₀ + (~a₃~a₂~a₁~a₀ + 1) = 10000₂ = 0
    (a₃a₂a₁a₀ + 1) + ~a₃~a₂~a₁~a₀ = 10000₂ = 0
位权展开
a₃a₂a₁a₀   = -2³·a₃ + 2²·a₂ + 2¹·a₁ + 2⁰·a₀
~a₃~a₂~a₁~a₀ = -2³·~a₃ + 2²·~a₂ + 2¹·~a₁ + 2⁰·~a₀

a₃a₂a₁a₀ + ~a₃~a₂~a₁~a₀
  = -2³ + 2² + 2¹ + 2⁰ = -1
结论 把 a₃a₂a₁a₀ 与它的逐位取反相加，与 -1 同值； 因此「取反 ＋ 1」得到的就是该数的相反数。
表达式值
a₃a₂a₁a₀ + ~a₃~a₂~a₁~a₀1111₂
1111₂ 按有符号解释-1
10000₂（4 位溢出后）0
※ 4 位寄存器保存不了 10000₂，最高位自然丢失，结果即为 0。
