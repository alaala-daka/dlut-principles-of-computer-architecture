过程的执行方法：执行过程所必需的事项

要点 要执行一个过程，调用方与被调用方之间必须完成下面这 6 件事。
① 把参数的值放在过程可以访问的位置
② 把控制转移到过程
③ 确保过程内部处理所需的内存资源
④ 执行过程内部的处理
⑤ 把结果（返回值）放在调用者可以访问的位置
⑥ 把控制返回原来的位置
说明
  • ① 与 ⑤ 处理的是参数的传递与返回值的回送。
  • ② 与 ⑥ 处理的是控制流的转移与返回。
  • ③ 与 ④ 是过程本体在运行中所需要的内存资源与处理本身。

过程的执行方法：各项事务在 MIPS 中的实现

序号 执行过程所必需的事项 在 MIPS 中的实现
① 把参数的值放在过程可以访问的位置 $a0 - $a3（参数寄存器）
② 把控制转移到过程 用 jal 指令操作 PC、$ra
③ 确保过程内部处理所需的内存资源 内存内（栈）
④ 执行过程内部的处理 过程内部的指令序列
⑤ 把结果（返回值）放在调用者可以访问的位置 $v0 - $v1（返回值寄存器）
⑥ 把控制返回原来的位置 jr $ra
说明 ① 与 ⑤ 之所以能用寄存器完成，是因为 MIPS 事先约定了参数寄存器 $a0-$a3 与 返回值寄存器 $v0-$v1；而 ② 与 ⑥ 则靠 jal / jr 这一对指令把返回地址写入并取回 $ra。

过程调用时的栈操作：寄存器值的保存规则

  • 当过程 A 调用过程 B 时，必须把 A 中正在使用的寄存器里的数据退避（保存）到内存（栈）中。
  • 哪些寄存器需要退避，是由寄存器本身决定的，与具体程序无关。
寄存器是否退避
$s0 - $s7（退避レジスタ） 要退避。日语称退避レジスタ，即被调用者保存寄存器。
$ra（リターンアドレス） 要退避。即返回地址。
$t0 - $t9（一時レジスタ） 不退避。即临时寄存器；如果其值不会被覆盖，也可以不退避。
做法 调用 B 时，把上述寄存器的值压栈；B 的执行结束后，再从栈中出栈， 把值恢复到原来的寄存器中。
源代码
int main(){
    a();
}
void a(){
    b();
    c();
}
要点
  • 被调用者（B）负责保证 $s0 - $s7 与 $ra 的值不变。
  • 调用者（A）自己负责 $t0 - $t9：若不使用，就不必退避。

过程调用之间保持不变的内容

保持（调用前后值不变）
$s0 - $s7　被调用者保存寄存器
$sp　栈指针
$fp　帧指针
$gp　全局指针
$ra　返回地址
被调用的过程必须保证这些寄存器在返回时与调用前完全相同。
不保持（调用后可能被改写）
$t0 - $t9　临时寄存器
$a0 - $a3　参数寄存器
$v0 - $v1　返回值寄存器
这些寄存器如果需要在调用后继续使用，必须由调用者自己提前退避。
小结 过程调用时，「$s0 - $s7、$sp、$fp、$gp、$ra 由被调用者负责保持不变」， 「$t0 - $t9、$a0 - $a3、$v0 - $v1 由调用者自行负责」—— 这正是前面所说「寄存器值的退避规则」的具体内容。

内存的释放

  • 动态数据的内存在 C 语言中用 free() 释放。
忘记释放 → 造成内存泄漏（日语：メモリ・リーク，memory leak）。

确认问题：递归过程 fact 的汇编代码

题目 把下面的 C 语言源代码编译之后，得到的 MIPS 汇编代码会是什么样子？（空栏 (1) - (10) 请自行填入）
源代码
int fact (int n){
    if(n<1)
        return 1;
    else
        return n * fact(n-1);
}
寄存器的对应
n：$a0
条件 调用 fact 时，需要把 $a0、$ra 的值退避。
MIPS 汇编（前半：递归的基准情形）
fact:
    addi $sp, (1), (2)        # 确保 2 个字
    sw   $ra, 4($sp)           # 退避
    sw   $a0, 0($sp)           # 退避
    slti $t0, $a0, 1           # n<1 吗？
    beq  $t0, $zero, (3)      # 分支
    addi $v0, $zero, 1         # 设置返回值
    addi $sp, (4), (5)        # 去掉 2 个字
    jr   (6)                  # 返回
MIPS 汇编（后半：递归调用与返回）
L1:
    addi $a0, $a0, -1          # 参数 n-1
    jal  (7)                  # 调用 fact
    lw   $a0, 0($sp)           # 恢复寄存器
    lw   $ra, 4($sp)           # 恢复寄存器
    addi $sp, (8), (9)        # 去掉 2 个字
    mul  $v0, $a0, $v0         # n*fact(n-1)
    jr   (10)                 # 返回
