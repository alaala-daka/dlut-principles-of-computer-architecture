分支处理

用途 用于实现 C 语言的条件判断与循环（if、while、for 等）。 
beq $s0, $s1, L1    # $s0 与 $s1 的值相等时，跳转到带标号 L1 的指令
                    # (branch on equal)
bne $s0, $s1, L1    # $s0 与 $s1 的值不相等时，跳转到带标号 L1 的指令
                    # (branch on not equal)
I 格式
op rs rt imm.
6bit 5bit 5bit 16bit 
beq (rs), (rt), (imm.)
bne (rs), (rt), (imm.)
要点 用带符号 16bit 整数进行相对地址指定：立即数字段不是地址本身， 而是相对程序计数器的偏移量（以指令为单位的相对地址）。
标号 L1 只是书写上的记号，汇编器会把它换算成偏移量后填入 imm. 字段。

分支处理：程序计数器（PC）

  • PC：program counter（程序计数器）。
  • 保存着当前正在执行的指令所在地址的寄存器。
  • 它不在 32 个通用寄存器之中。
  • MIPS 的指令是 32 位（4 字节），所以当前 PC 为 2048 时，下一条指令的地址是…
  • 通常，每执行 1 条指令就进行 PC = PC + 4 这一动作。
  • 但是，遇到 J 指令时，会把 PC 的低 28 位替换为指定的值。
PC 与指令地址
指令地址
当前正在执行的指令2048
下一条指令2052
再下一条指令2056
因为 1 条指令占 4 字节，所以每执行 1 条指令 PC 就 +4； 只要顺序执行，地址就依次递增。
J 指令的例外 j 指令只替换 PC 的低 28 位，高 4 位保持不变（下一节详细说明）。

无条件转移

用途 无条件跳转。 
j L1    # 无条件跳转到带标号 L1 的指令
J 格式
op address
6bit 26bit
op:指令操作码
address:绝对地址
注意 address 字段中存放的并不是真正的地址，而是实际地址的 1/4 的值 （也就是「第几条指令」）。
因此 26 位可以覆盖 226 条指令，即 228 字节的地址空间。
正因为指令按 4 字节对齐，地址的最低 2 位永远是 00，才可以省略不存。

无条件转移：PC 的值的变化

回顾：j L1
op address
6bit 26bit
1000 j L1 → 跳转到 1024（address = 256 = 1024 ÷ 4）， 机器码为 000010 00000000000000000100000000。
上位 4 位不变 j 指令只改写 PC 的低 28 位，所以高 4 位保持原样， 跳转只能在同一 256MB 区域（同一段）内进行。
低 2 位恒为 00 address 字段存放的是「实际地址 ÷ 4」，拼回地址时要左移 2 位， 因此低 2 位始终是 00。
PC 的值的变化（PC = 1000 → 1024）
PC = 0000 0000 0000 0000 0000 0011 1110 1000    # 1000
     ↓  把低 28 位替换为 26bit 的 address×4
PC = 0000 0000 0000 0000 0000 0100 0000 0000    # 1024
     ↑ 高 4 位不变          ↑ 这一段是 26bit 的 address（×4 之后）

与分支处理对应的汇编代码

（例）
if(i==j) f=g+h; else f=g-h;
寄存器分配
f : $s0
g : $s1
h : $s2
i : $s3
j : $s4
汇编代码
bne $s3, $s4, Else    # i != j 则跳到 Else
add $s0, $s1, $s2     # f = g + h（then 部分）
j   Exit              # 跳过 else 部分
Else: sub $s0, $s1, $s2  # f = g - h（else 部分）
Exit:                 # 汇合点
说明 用相反的条件（bne）跳过 then 部分， then 部分结束后再用 j 跳过 else 部分， 两个分支最终在标号 Exit 处汇合。

确认问题：解答与小结

空栏 参考答案 说明
(1) sll 用逻辑左移 2 位求出 j×4，即元素 a[j] 的字节偏移。
(2) beq i == a[j] 时跳出循环：条件成立就转移到 Exit。
(3) addi 做立即数加法：i = i + 1。
(4) 1 循环变量每次加 1。
(5) j 循环体结束，无条件跳回循环开头。
(6) Loop 跳转目标标号，即循环的条件判断处。
小结 while 循环的固定结构：标号 Loop → 条件判断（beq/bne）→ 循环体 → j Loop。 条件转移负责「跳出」，无条件转移负责「回到开头」。

确认问题：解答（Loop = 76810）

题目 标号 Loop 的地址为 76810；请用 16 位、26 位二进制分别回答红色标出的 Exit、Loop 对应的值。
① Exit：beq 的 16bit 偏移量
偏移量 = (Exit − (PC + 4)) ÷ 4
       = (780 − (768 + 4)) ÷ 4
       = (780 − 772) ÷ 4 = 8 ÷ 4 = 2
16 位二进制（补码形式）：
0000 0000 0000 0010
即 2，表示「从下一条指令再往后 2 条指令」。
② Loop：j 的 26bit 地址字段
address = 目标地址 ÷ 4 = 768 ÷ 4 = 192
26 位二进制：
00000000000000000011000000
即 192；拼回地址时左移 2 位就得到 768。
要点 条件转移的立即数是相对偏移量（以指令为单位、相对 PC+4）， 而 j 指令的地址字段是绝对地址 ÷ 4。

确认问题：解答（bne 的偏移量）

题目 把指令用二进制表示时，红色标出的 Loop 对应的值是什么？请用 16 位二进制回答。
计算过程
PC        = Loop + 8   （bne 自身的地址）
PC + 4    = Loop + 12
目标地址  = Loop + 0
偏移量    = (目标 − (PC+4)) ÷ 4
          = (Loop − (Loop + 12)) ÷ 4
          = −12 ÷ 4 = −3
16 位二进制（补码）
1111 1111 1111 1101
−3 的 16 位补码 ⇒ 0xFFFD，即「向前（低地址方向）跳 3 条指令」。
小结 条件转移的立即数是带符号偏移量：正数向后跳，负数向前跳，范围是 −32768 ～ 32767。

大小比较

对应 < 的比较指令 下面的两条指令把「小于」的判断结果写成 0／1，存入寄存器。 
slt  $t0, $s0, $s1
slti $t0, $s0, 5
  • slt $t0, $s0, $s1 …当 $s0 小于 $s1 时，把 $t0 置为 1；否则置为 0。
  • slti $t0, $s0, 5 …当 $s0 小于 5 时，把 $t0 置为 1；否则置为 0。
R 格式
op rs rt rd shamt funct
6bit 5bit 5bit 5bit 5bit 6bit 
slt (rd), (rs), (rt)
I 格式
op rs rt imm.
6bit 5bit 5bit 16bit 
slti (rt), (rs), (imm.)

大小比较：while 循环的例子

（例）
while(i>=0) i=i–1;
寄存器分配
i : $s1
汇编代码
Loop: slt  $t0, $s1, $zero   # $t0 = (i < 0)
      bne  $t0, $zero, Exit  # i < 0 则跳出循环
      addi $s1, $s1, -1      # i = i - 1

说明 while(i>=0) 的跳出条件是 i < 0。 由于没有「大于等于」的指令，就先用 slt 求出 i < 0 的布尔值， 再用 bne 与 $zero 比较来判定。

大小比较：为什么 slt、slti 不直接分支？

问 slt、slti 为什么不直接分支？
  • → 因为指令会变得过于复杂。
  • → 会导致时钟周期时间延长等代价。
也就是说：把「比较」与「转移」分成两条指令，可以让每条指令都保持简单且等长， 有利于流水线化与提高时钟频率。
问 对应 >、>= 等条件的指令呢？
  • 作为伪指令提供。
  • 由汇编器转换为等效的指令序列。
伪指令含义
blt (branch less than)小于则转移
bgt (branch greater than)大于则转移
ble (branch less or equal)小于等于则转移
bge (branch greater or equal)大于等于则转移

寻址模式（addressing mode）

  • 不同的指令对操作数的解释方式各不相同。
  • → 指令所操作的对象，
    • （e.g., add 指令中要相加的值）
  • 指令所需要的地址，
    • （e.g., j 指令的跳转目标地址）
  • 会因指令而异。
  • 把这些解释方式称为寻址模式。
寻址模式的种类
寄存器寻址register addressing
基址相对寻址base addressing
立即数寻址immediate addressing
PC 相对寻址PC-relative addressing
伪直接寻址pseudo direct addressing
接下来的 5 页会用具体的指令与位模式逐一说明这 5 种模式。

寄存器寻址（register addressing）

定义 把指定寄存器中的内容作为操作数。
例：add $t0, $s0, $s1
op rs rt rd shamt funct
000000 10000 10001 01000 00000 100000
add $s0 $s1 $t0 — add
解读 三个操作数全部放在寄存器里：rs = $s0（16）、rt = $s1（17）、 rd = $t0（8）；op = 0 且 funct = 32 共同表示「加法」。 这正是 R 格式最典型的用法。

立即数寻址（immediate addressing）

定义 把指定的常数作为操作数。
例：andi $s1, $s0, 24
op rs rt immediate
001100 10000 10001 0000000000011000
andi $s0 $s1 24
解读 andi 是 I 格式的逻辑与指令：立即数字段里直接写着常数 24（16 位二进制 0000000000011000）， 运算时不需要访问存储器，因此执行很快。
注意：I 格式中目的寄存器放在 rt 的位置上（此处 rt = $s1）。

基址相对寻址（base addressing）

定义 把「指定寄存器中的内容 ＋ 常数」所指的存储器地址中的内容作为操作数。
例：lw $t0, 12($s0)
op rs rt immediate
100011 10000 01000 0000000000001100
lw $s0（基址） $t0（目的） 12（偏移量）
解读 先从 $s0 中取出基址，再加上常数偏移 12， 得到存储器地址 $s0 + 12，最后把该地址中的内容装入 $t0。 数组访问就是靠这种模式实现的。
地址计算
有效地址 = (rs) + immediate　→　($s0) + 12

PC 相对寻址（PC-relative addressing）

定义 表示「(PC+4) ＋（指定常数 × 4）」的地址。
例：bne $t0, $s0, Label
op rs rt immediate
000101 01000 10000 0000000000001100
bne $t0 $s0 Label（偏移量）
解读 跳转目标 = (PC + 4) + 立即数 × 4。立即数是以指令条数为单位的相对偏移量， 乘 4 之后才变成字节偏移。条件转移（beq／bne）采用的就是这种模式。
相对寻址的优点
  • 只需 16 位就能表达偏移，不必在指令里塞进完整的 32 位地址。
  • 整个程序被装入存储器的任意位置时，相对转移依然正确（与位置无关）。

伪直接寻址（pseudo direct addressing）

定义 表示把「PC 的高 4 位」与「指定常数 × 4」拼接起来的地址。
例：j Label
op address
000010 00000000000010011100010000
j Label（目标 ÷ 4）
例：PC 与跳转目标
PC = 00101100000000000010011100010000 时，
上述指令的跳转目标为：
00100000000000001001110001000000
解读 高 4 位取当前 PC 的高 4 位（此例为 0010），低 28 位由 address × 4 给出， 两部分拼接即可得到 32 位跳转地址。所以 j 指令能在同一段内跳到任意位置。

32 位的立即数操作数（1）

  • 指令长度是 32 位。
  • → 因此无法直接处理 32 位的操作数，但是…
  • 可以把它分成高位与低位，用 2 条指令读入。
想装入的 32 位数
0000 0000 0011 1101 0000 1001 0000 0000

低位 16 位230410
思路 先用 lui 把高 16 位放进寄存器，再用 ori 把低 16 位「或」进去。 两条指令合起来就构造出完整的 32 位常数。

0000 0000 0011 1101 0000 0000 0000 0000
② 装入低位
ori $s0, $s0, 2304 # or 运算 (or immediate)
0000 0000 0011 1101 0000 1001 0000 0000

确认问题：解答与小结

题号 寻址模式 依据
(1) 基址相对寻址
(base addressing)		 有效地址 = 寄存器内容 ＋ 常数，例如 lw $t0, 12($s0)。
(2) PC 相对寻址
(PC-relative addressing)		 目标地址 = (PC+4) + 常数×4，例如 beq／bne。
(3) 寄存器寻址
(register addressing)		 操作数就在寄存器里，例如 add $t0, $s0, $s1。
(4) 伪直接寻址
(pseudo direct addressing)		 PC 高 4 位 ＋ 常数×4，例如 j Label。
(5) 立即数寻址
(immediate addressing)		 操作数就是指令中的立即数，例如 andi $s1, $s0, 24、addi。
小结 寻址模式决定「指令里的字段到底意味着什么」。寄存器与立即数模式最快； 基址相对模式支撑数组与结构体访问；PC 相对与伪直接模式用于转移， 前者与位置无关、后者可覆盖较大范围。
