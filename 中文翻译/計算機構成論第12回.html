    → 因此尾数部分的 23bit 中不保存这个 1。

误差与舍入

  • 双精度下，1 和 2 之间能够表示的数的个数是多少？
252-1 个
→ 比这更多的个数都无法表示，所以只能用最接近的表示来表达。
  • 「舍入」（日文：丸め / rounding）
把数值做四舍五入、进位取整或截断，收进指定的位数之中。
四舍五入　1.4→1.0　1.5→2.0
进位取整　1.4→2.0　1.5→2.0
截断　　　1.4→1.0　1.5→1.0
结论 这样就会产生与本来应当表示的值之间的误差，称为舍入误差（日文：丸め誤差 / rounding error）。

信息丢失

…+((1.510×1038) + 0.00…×1038)
= 0
((-1.510×1038) + (1.510×1038)) + (1)
0 + 1

现象 把绝对值大的数与绝对值小的数相加时，绝对值小的数会被忽略掉。
结论 根据计算顺序的不同，有可能回避掉这种误差。
术语 这种现象称为信息丢失（日文：情報落ち / loss of information）。

有效位丢失（相消）

  • 在浮点数的运算中，有效位数变少的现象。
    • 发生在非常接近的数值之间做减法、以及计算结果接近于 0 的加减运算时。
√1001 - √999
= (3.163858410×101) - (3.160696110×101)   ← 有效位 8 位
= (3.162310×10-2)                ← 有效位 5 位
= (3.162300010×10-2)             ← 用 0 填充后看起来像 8 位，但…
        真正的差是…
    3.16227805545…×10-2
术语 这种现象称为有效位丢失（相消，日文：桁落ち / cancellation）。
