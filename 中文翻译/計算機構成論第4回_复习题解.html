确认问题（2）:MIPS 指令与存储器相关术语

处理MIPS 运算指令
加法add
减法sub
从存储器读出 1 个字lw
向存储器写入 1 个字sw
提问答案
按对齐限制存放的字，顺序读出时存储器访问以多少字节为单位？4 字节（= 32 位 = 1 字）
把字按高位字节到低位字节的顺序存入存储器，这种方式叫什么？大端序（big-endian）
把字按低位字节到高位字节的顺序存入存储器，这种方式叫什么？小端序（little-endian）
指出下一条要执行的程序存储器地址的东西叫什么？程序计数器（PC: program counter）
把处理所需的数据和程序预先存放在存储器中的方式叫什么？存储程序方式
回顾 对齐限制要求字的起始地址是 4 的倍数；因此在 32 位 MIPS 上， 一次 lw / sw 正好访问 4 个连续字节。
2 / 4

确认问题（3）:汇编指令对应的 C 语句

题目 写出下列汇编指令所对应的 C 语句。
汇编指令
add $s0, $s1, $s2
sub $s0, $s0, $s3
add $s0, $s0, $s4
寄存器的对应
f : $s0
g : $s1
h : $s2
i : $s3
j : $s4
答案
f = g + h - i + j;
逐条对照 add $s0,$s1,$s2 → f = g + h
sub $s0,$s0,$s3 → f = f - i
add $s0,$s0,$s4 → f = f + j
3 / 4

确认问题（4）:数组地址与大端序

题目 在 MIPS 中声明了 int 型数组 A[100]。 设存放 A[0] 的存储器地址为 1000。
(1) 求 A[50] 所在存储单元的首地址
提示：int 型 → 4 字节（32 位）

1000 + 4 × 50 = 1200
答案 A[50] 的首地址 = 1200
(2) MIPS 为大端序，求各字节内容
A[0] = FF332211₁₆

地址 1000 : 11111111   # FF
地址 1001 : 00110011   # 33
地址 1002 : 00100010   # 22
地址 1003 : 00010001   # 11
要点 大端序把字的高位字节放在低地址处，因此 FF 位于 1000， 顺序依次为 FF → 33 → 22 → 11。
4 / 4
