二进制数的乘法

  • 正数 × 正数
    • 与十进制数一样可以做竖式笔算（日文：筆算 / longhand）。
    • 位数是乘数的位数与被乘数的位数相加的结果。 2m 种 × 2n 种 → 2(m+n) 种
      0011          3₁₀  …被乘数
   ×  0110          6₁₀  …乘数
  ──────────
      0000
     0011
    0011
   0000
  ──────────
   00010010         18₁₀ …积
竖式的读法
乘数从最低位开始逐位检查：该位为 0 就写一行 0000，该位为 1 就写一行被乘数 0011；每往左一位整体左移一位，最后把各行相加。

二进制数的乘法

  • 正数 × 负数
    • 把乘数和被乘数做符号扩展（日文：符号拡張 / sign extension）之后竖式笔算。
    • 把高位比特截断。

同样的比特串，按无符号解释就得到 30₁₀，与 -18₁₀ 完全不同。
说明 乘数的 1111 是符号扩展出来的部分，因此竖式中会出现若干行全 1 的部分积；相加后只保留低 8 位，高位的 00000010 被截断。

二进制数的乘法

  • 负数 × 负数
    • 与正数 × 负数的处理完全相同。
  11111101         -3₁₀
× 11111010         -6₁₀
──────────────
  11111101
   11111101
    11111101
     11111101
      11111101
       11111101
──────────────
0000000000010010  ← 截断
                  18₁₀
符号怎么看
两个操作数的最高位都是 1（都是负数）， 相乘后符号自然为正：结果的低 8 位 00010010₂ = 18₁₀。
要点 竖式笔算本身只关心比特串，符号由操作数的格式决定； 高位被截断后，剩下的低位比特恰好就是正确的补码结果。

二进制数的除法

  • 带符号除法
    • 被除数 = 商 × 除数 + 余数
■(+7) / (+2) = (+3) 余 (+1)
■(-7) / (-2) = (+3) 余 (-1)
■(-7) / (+2) = (-3) 余 (-1)
■(+7) / (-2) = (-3) 余 (+1)
✕(+7) / (-2) = (-4) 余 (-1) ← 被除数与余数的符号不一致，不成立
为什么不行？
代回公式检验：(-4) × (-2) + (-1) = 8 - 1 = 7， 数值上确实等于被除数——但余数的符号是负的，与被除数 +7 相反， 所以这一组结果不符合下面这条约定。
约定 被除数的符号与余数的符号必须相同。（日文：被除数と剰余の符号は同じでなければならない）

处理负数的除法器电路

  • 把被除数与除数的符号记下来，事后施加符号。
回顾（二进制数的除法：带符号除法）
被除数 = 商 × 除数 + 余数
■(+7) / (+2) = (+3) 余 (+1)
■(-7) / (-2) = (+3) 余 (-1)
■(-7) / (+2) = (-3) 余 (-1)
■(+7) / (-2) = (-3) 余 (+1)
✕(+7) / (-2) = (-4) 余 (-1) ← 余数符号与被除数不一致，不成立
约定 被除数的符号与余数的符号必须相同。
符号的施加规则
(i)被除数与除数的符号不同时，把商取为负；
(ii)把被除数与余数的符号对齐。
说明 除法电路内部只做无符号的「移位—减法」循环，正负号只是进入电路前与离开电路后各处理一次。

乘法・除法指令

mult $s2, $s3       # 有符号乘法

multu $s2, $s3      # 无符号乘法
    Hi, Lo = $s2 × $s3

div $s2, $s3        # 有符号除法
    Lo = $s2 / $s3,  Hi = $s2 % $s3

divu $s2, $s3       # 无符号除法
    Lo = $s2 / $s3,  Hi = $s2 % $s3

mvhi $s1            # move from hi
    $s1 = Hi

mvlo $s1            # move from lo
    $s1 = Lo
指令与寄存器的对应
乘法的 64 位积放在 Hi、Lo 这一对寄存器里； 除法的商放在 Lo、余数放在 Hi。 要用普通指令访问这两个值，就再用 mvhi / mvlo 搬到通用寄存器。
说明 mvhi / mvlo 与第 6 讲的 move 不同， 后者是汇编器的伪指令；而 mvhi / mvlo 是访问 Hi、Lo 的专门指令。

本讲小结 二进制乘法与十进制一样可以竖式笔算；硬件上反复做「看乘数的最低位 → 加被乘数 / 什么都不做 → 移位」， 乘法器电路由第 1 版（被乘数左移、积单独存放）经第 2 版（积右移、ALU 缩到 32 位） 演进到第 3 版（积与乘数共用一个 64 位寄存器）。除法做「移位 — 减法」并看被除数的 MSB 决定商的这一位， 第 2 版把除数右移改为余数／被除数左移。有符号数则先记下符号、把负数转正，最后再施加符号—— 被除数的符号与余数的符号必须一致。MIPS 用 Hi、Lo 一对寄存器复用同一套乘除硬件。
