汇编器

  • 把汇编代码转换为机器语言（这一过程称为汇编）。
  • 输出到目标文件（目的文件）中（后述）。
  • 把伪指令替换为实际的指令。
伪指令的展开（例）
blt $t0, $t1, Label   # 小于则转移（伪指令）
  → slt $t2, $t0, $t1    # $t2 = ($t0 < $t1)
    bne $t2, $zero, Label # $t2 ≠ 0 则转移到 Label

move $t0, $t1         # 寄存器间复制（伪指令）
  → add $t0, $zero, $t1   # $t0 = 0 + $t1
要点 汇编器把「一条」伪指令展开为「多条」实际指令，展开结果与原本的语义完全等价。

链接器

  • 把分别独立编译、汇编好的程序拼接起来，生成一个可执行的目标文件。
  • 于是不必为了改动而重新编译整个大型程序。
  • 可以在事后链接像库那样复用性高的模块。
  • 解决外部引用（例如：位于其它文件中的标号名）。
  • 决定程序在内存中的布局。
重定位 对采用绝对寻址（即非基址相对寻址）的指令，要调整其地址（relocation）。
链接器解决的问题
  • 合并多个目标模块
  • 解决外部符号引用
  • 分配并确定各段地址
  • 修正绝对地址（重定位）

从 C 程序到汇编代码的转换

题目 请把下面的 C 语言源代码改写为汇编代码。
C 源代码
void swap(int v[], int k){
    int t;
    t = v[k];
    v[k] = v[k+1];
    v[k+1] = t;
}
寄存器分配
$a0 : v
$a1 : k
$t0 : t
—
请填入空白处（(1) ～ (7)）
swap:
    sll  $t1, $a1,  (1)        # $t1 = k*4
    add  $t1, (2),  (3)      # $t1 = &(v[k])
    lw   $t0, ( 4 )       # t = v[k]
    lw   $t2, ( 5 )       # $t2 = v[k+1]
    sw   $t2, ( 6 )       # v[k] = $t2
    sw   $t0, ( 7 )       # v[k+1] = t
    jr   $ra             # 返回
提示：sll 完成「下标 → 字节偏移」的换算；add 求出 v[k] 的地址；随后用 lw / sw 完成存取。

从 C 程序到汇编代码的转换:swap 的解答

题目 请把下面的 C 语言源代码改写为汇编代码。
C 源代码
void swap(int v[], int k){
    int t;
    t = v[k];
    v[k] = v[k+1];
    v[k+1] = t;
}
寄存器分配
$a0 : v
$a1 : k
$t0 : t
$t1 : 地址
$t2 : 临时值
$ra : 返回地址
汇编代码（解答）
swap:
    sll  $t1, $a1,  2        # $t1 = k*4
    add  $t1, $a0,  $t1      # $t1 = &(v[k])
    lw   $t0, 0($t1)       # t = v[k]
    lw   $t2, 4($t1)       # $t2 = v[k+1]
    sw   $t2, 0($t1)       # v[k] = $t2
    sw   $t0, 4($t1)       # v[k+1] = t
    jr   $ra             # 返回
编号答案含义
(1)2每个 int 占 4 字节，左移 2 位即乘以 4
(2)$a0数组首地址 v
(3)$t1字节偏移量 k*4
(4)0($t1)取 v[k]
(5)4($t1)取 v[k+1]，偏移 4 字节
(6)0($t1)写回 v[k]
(7)4($t1)写回 v[k+1]

从 C 程序到汇编代码的转换:sort 的八个步骤

C 源代码
void sort(int v[], int n){
    int i, j;
    for(i=0; i<n; i++){
        for(j=i-1; j>=0 && v[j]>v[j+1]; j--){
            swap(v,j);
        }
    }
}
寄存器分配
$a0 : v
$a1 : n
$s0 : i
$s1 : j

① 保存寄存器
② 保存参数
③ 外层循环
④ 内层循环
⑤ 调用 swap
⑥ 内层循环
⑦ 外层循环
⑧ 恢复寄存器～返回
