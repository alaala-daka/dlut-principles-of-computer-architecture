题目 对下列各数进行算术移位、逻辑移位。
小题题目答案
(1)11101010 算术左移 1 位11010100
(2)10101010 算术右移 1 位11010101
(3)10101010 逻辑左移 1 位01010100
(4)10101010 逻辑右移 1 位01010101
移位规则
种类移入位效果

确认问题（3）:用 2 的补数实现减法

  • 设有两个二进制数 A、B。
  • 要求 A - B 的结果时，只需先取被减数 B 的 2 的补数，再与 A 相加。
原理
A - B  =  A + (-B)  =  A + (~B + 1)

即：把减法 统一转换为加法，
    加法器电路不必为减法单独设计。
例:求 B 的 2 的补数
B = 00000101₂  (= 5)
~B = 11111010
-B = 11111011   # 逐位取反再加 1

确认问题（4）:用 8 位二进制计算

题目 用 8 位二进制数计算下列各式。
(1) (-1) + 1 = 0
  11111111   # -1
+ 00000001   #  1
-----------
1 00000000   # 最高位进位溢出，8 位结果 = 00000000 = 0
(2) 3 + (-2) = 1
  00000011   #  3
+ 11111110   # -2
-----------
1 00000001   # 8 位结果 = 00000001 = 1
(3) 3 + (-5) = -2
  00000011   #  3
+ 11111011   # -5
-----------
  11111110   # = -2
各数的 2 的补数（参考）
 1 = 00000001  → 11111111  # -1
 2 = 00000010  → 11111110  # -2
 5 = 00000101  → 11111011  # -5
注意：8 位运算中最高位产生的进位被丢弃（第 9 位的 1 超出 8 位范围），这正是 2 的补数能让加法「自动处理正负号」的原因。
