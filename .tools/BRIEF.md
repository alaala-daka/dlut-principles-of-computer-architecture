## 0. 每讲都一样的部分

- 工作目录：`D:\trans-for-CS`
- 页面图像（**必看，逐页**）：`.tools/newpdf_pages/{讲次}/p01.png … pNN.png`（用 `read_image`）
- 文本稿：`日语原文-md/第N回_*.md`；坐标版：`.tools/newpdf_txt/*.txt`
- 版式实物参照（**动手前通读一遍**）：`中文翻译/計算機構成論第7回.html`、`中文翻译/計算機構成論第8回.html`
- 封面固定写法：
  - `cover__kicker` = `计算机组成原理 · 第 N 讲`
  - `cover__meta` = `大连理工大学 · 立命馆大学国际信息软件学院<br>薛昕惟`
  - `cover__badge` = `原讲义「…」<br>中文翻译版`（日文标题见各自任务卡）
  - 封面 `page-no` 加 `style="color:#8fb0cc"`
- 末页 = `参考文献` + `本讲小结` callout（第13、14回末页还要保留原文的
  「画像は教科書からのスキャンです。転載・頒布を禁止します。」→ 译作
  「本页图片为教科书扫描件，禁止转载与分发。」）
- 讲义里反复出现的 `講義内容` 目录页：**每一页都要照译**，并按**原图高亮的那一条**设置
  `.toc__item--active`（原图把当前小节标红/加箭头，必须看 PNG 确认，不能猜）。
- 完成后必须跑：
  ```powershell
  python .tools\check_overflow.py "中文翻译\計算機構成論第N回.html"
  ```
